📅 발표일: 2026년 3월 30일\

------------------------------------------------------------------------

# 1. 프로젝트 개요

## 1.1 프로젝트명

**내다**

## 1.2 한 줄 소개

얼굴 결제를 기반으로 포인트를 적립하고, AI 소비 분석을 통해 지역 후원과
지역경제 활성화를 연결하는 **구미 특화 ESG 금융 앱**

------------------------------------------------------------------------

## 1.3 기획 배경

### 문제 인식

-   지갑 없이 결제 불가 상황
-   반복적인 카드 결제 절차
-   얼굴 결제는 등장했지만 "결제 기능"에만 집중

### 시장 환경

-   얼굴 인식 결제는 빠르게 확산 중
-   그러나 지역경제·ESG 연계 서비스는 부족

### 해결 방향

-   얼굴 결제 + 지역 포인트 + ESG 후원 결합
-   결제 행위를 지역 선순환 구조로 확장

## 4.2 FacePay 결제 구조

### 등록

-   다각도 얼굴 촬영
-   128차원 벡터 암호화 저장
-   원본 이미지 미저장

### 결제 흐름

    카메라 촬영
    → Liveness 검증
    → 얼굴 벡터 추출
    → 서버 매칭
    → 결제 실행

Liveness는 매칭 이전 수행

------------------------------------------------------------------------

## 4.3 fcm 기능

# 5. 리스크 기반 인증 (RBA)

## 5.1 기본 원칙

얼굴 인증 = 기본 구조

------------------------------------------------------------------------

## 5.2 금액 기반 인증 정책

  금액          인증                                추가
  ------------- ----------------------------------- -----------
  5만원 미만    얼굴                                  없음
  5만원 이상    얼굴                                  전자 서명

------------------------------------------------------------------------

## 5.3 얼굴 유사도 기반 단계 인증

### 유사도 ≥ 80

-   바로 결제

### 유사도 70\~79

-   전화번호 가운데 4자리 확인 후 

### 완전 실패

-   전화번호 조회
-   계정 없으면 결제 차단 / 계정 생성 요청
-   계정 있으면 결제 차단 / 얼굴 재등록 요청

------------------------------------------------------------------------
