# AI-003 프론트 연결 가이드 (Front -> BE)

## 1. 호출 대상
- URL: `POST /api/v1/face/liveness/headpose/check`
- Content-Type: `multipart/form-data`
- 설명: 기대 방향(`expectedDirection`)과 실제 얼굴 방향이 일치하는지 검증

## 2. 요청 파라미터
- `expectedDirection` (문자열, 필수)
  - 허용값: `front`, `left`, `right`, `up`, `down`
- `image` (파일, 필수)
  - 카메라 프레임 이미지 1장

## 3. 응답 스키마
```json
{
  "expectedDirection": "left",
  "detectedDirection": "left",
  "matched": true,
  "yaw": -0.24,
  "pitch": 0.03,
  "confidence": 0.82
}
```

## 4. 프론트 기본 흐름
1. 카메라 화면에서 현재 챌린지 방향을 표시
2. 일정 주기(권장 1~2fps)로 프레임 1장을 캡처
3. 위 API로 `expectedDirection + image` 전송
4. `matched=true`이면 다음 챌린지 방향으로 진행
5. 모든 챌린지 통과 시 다음 단계(캡처/매칭/결제) 이동

권장 챌린지 순서:
- `left -> right -> up -> down -> front`

## 5. 에러 처리 규칙
- `400`
  - `INVALID_POSE`: 방향 값 오류
  - `NO_FACE`: 얼굴 미검출
  - `MULTIPLE_FACES`: 다중 얼굴
  - `EMPTY_IMAGE`, `INVALID_IMAGE`: 이미지 문제
- `503`
  - `AI_UNAVAILABLE`: AI 서버 일시 장애
- `504`
  - `AI_TIMEOUT`: AI 응답 지연

프론트 권장 UX:
- `NO_FACE`: "얼굴이 화면 안에 오도록 맞춰주세요."
- `MULTIPLE_FACES`: "한 명만 화면에 나오게 해주세요."
- `AI_TIMEOUT/AI_UNAVAILABLE`: "네트워크/서버 상태를 확인 후 다시 시도해주세요."

## 6. 요청 예시 (JavaScript)
```javascript
async function checkHeadPose(expectedDirection, imageBlob) {
  const formData = new FormData();
  formData.append("expectedDirection", expectedDirection);
  formData.append("image", imageBlob, "frame.jpg");

  const res = await fetch("/api/v1/face/liveness/headpose/check", {
    method: "POST",
    body: formData,
  });

  const data = await res.json();
  if (!res.ok) {
    throw data; // { code, message }
  }
  return data;
}
```

## 7. 재시도/중복호출 정책
- 같은 방향에서 `matched=false`면 최대 3~5회 재시도
- 요청 중에는 다음 요청을 보내지 않도록 잠금 처리(중복 호출 방지)
- 3회 이상 연속 실패 시 안내 문구 강화 및 카메라 리셋 버튼 제공

## 8. 성능 권장값
- 프레임 해상도: 긴 변 320~480px 권장
- 전송 주기: 1~2fps 권장
- 이미지 품질: JPEG 70~80 권장

## 9. 보안/운영 유의사항
- 프론트는 AI 서버를 직접 호출하지 않고 반드시 BE만 호출
- 로그에 원본 이미지/민감정보를 남기지 않기
- 화면 이탈/백그라운드 전환 시 카메라 스트림 정리
