# Front 담당자 체크리스트

## 0. 역할 정의
- [ ] Front 책임 범위를 팀에 공유했다.
- [ ] Front 범위를 `촬영/사용자 안내/Back API 호출/결과 표시`로 확정했다.
- [ ] Back/AI와 경계를 합의했다.

## 1. 착수 전 합의
### 1.1 API 계약 (Front <-> Back)
- [ ] 등록 API 요청/응답 스키마를 확인했다.
- [ ] 검색 API 요청/응답 스키마를 확인했다.
- [ ] 에러코드별 UI 메시지 정책을 합의했다.

### 1.2 UX 플로우
- [ ] 등록 플로우(정면/좌/우/상/하)를 확정했다.
- [ ] 검색 플로우(촬영 -> 결과 표시)를 확정했다.
- [ ] 실패/재시도 UX를 확정했다.

### 1.3 개인정보/보안
- [ ] 원본 이미지 로컬 영구 저장 금지 정책을 반영했다.
- [ ] 민감 데이터 로그 출력 금지 정책을 반영했다.
- [ ] HTTPS 통신만 허용하도록 확인했다.

## 2. 카메라/이미지 처리
### 2.1 권한 및 기기 대응
- [ ] 카메라 권한 요청/거부 처리 구현
- [ ] 권한 거부 시 대체 안내 UI 구현
- [ ] 전면/후면 카메라 정책 확정 및 구현

### 2.2 촬영 파이프라인
- [ ] CameraX 기반 캡처/분석 파이프라인 구현
- [ ] JPEG 압축 품질을 적용했다. (예: 75~85)
- [ ] 과도한 해상도 업로드를 제한했다.
- [ ] 프레임 회전/방향 처리 보정 완료

### 2.3 등록 촬영 UX
- [ ] 포즈별 가이드 오버레이를 구현했다.
- [ ] 포즈 유지 시간(hold) 조건을 반영했다.
- [ ] 포즈별 성공/실패 피드백 UI를 구현했다.

## 3. 네트워크 연동
### 3.1 API 클라이언트
- [ ] Retrofit/OkHttp API 인터페이스 구현
- [ ] multipart 업로드 구현
- [ ] 인증 헤더 처리 구현
- [ ] timeout 설정 구현

### 3.2 전송 제어 (실시간 검색)
- [ ] 최대 전송 주기 제한 구현 (예: 100ms)
- [ ] in-flight 요청 수 제한 구현
- [ ] 네트워크 지연 시 오래된 프레임 드롭 정책 구현
- [ ] 배터리/발열 고려한 전송 정책 반영

## 4. 상태 관리/UI
### 4.1 상태 관리
- [ ] 촬영 상태(대기/촬영/업로드/완료) 관리 구현
- [ ] API 로딩 상태/재시도 상태 관리 구현
- [ ] 화면 회전/백그라운드 복귀 상태 복구 구현

### 4.2 결과 화면
- [ ] `matched`, `bestUserId`, `similarity`, `threshold` 표시 구현
- [ ] 후보 목록(topK) 표시 구현
- [ ] 미매칭 시 안내 문구/재시도 버튼 구현

### 4.3 에러 UX
- [ ] `NO_FACE` 대응 메시지 구현
- [ ] `MULTIPLE_FACES` 대응 메시지 구현
- [ ] `AI_TIMEOUT`/네트워크 오류 대응 UI 구현

## 5. Passive Liveness (프론트 정책)
- [ ] 적용 여부를 팀에서 최종 합의했다.
- [ ] 눈 깜빡임/머리 움직임 조건을 구현했다.
- [ ] liveness 통과 전 서버 전송 정책을 정의했다.
- [ ] 오탐/미탐 UX를 점검했다.

## 6. 개인정보/보안 점검
- [ ] 이미지 파일을 디스크에 저장하지 않는다.
- [ ] 디버그 로그에서 이미지 바이트를 출력하지 않는다.
- [ ] 스크린샷/녹화 민감 정책 필요 여부를 확인했다.
- [ ] 앱 설정값(BASE_URL 등) 외부 노출 정책을 점검했다.

## 7. 테스트
### 7.1 기능 테스트
- [ ] 등록 5포즈 시나리오 성공
- [ ] 검색 시나리오 성공
- [ ] 네트워크 끊김/복구 시나리오 성공

### 7.2 기기 테스트
- [ ] 저사양/고사양 단말 테스트
- [ ] 다양한 해상도/비율 단말 테스트
- [ ] 저조도/역광 환경 테스트

### 7.3 성능 테스트
- [ ] fps/업로드 지연 측정
- [ ] 발열/배터리 사용량 측정
- [ ] 앱 메모리 사용량 측정

## 8. 배포 준비
- [ ] BASE_URL 환경 분리(dev/stage/prod) 적용
- [ ] 릴리즈 빌드에서 디버그 로그 제거
- [ ] 크래시 리포팅/분석 도구 연동
- [ ] 사용자 가이드(촬영 방법) 문구 점검

## 9. 문서화/인수인계
- [ ] 화면 플로우 문서 최신화
- [ ] API 연동 문서 최신화
- [ ] 에러 메시지 매핑표 최신화
- [ ] QA 체크리스트 공유

## 10. 완료 기준 (Definition of Done)
- [ ] 사용자 기준 등록/검색 플로우가 끊김 없이 동작한다.
- [ ] 네트워크/AI 오류 시 사용자 안내가 명확하다.
- [ ] 원본 이미지 비저장 정책이 준수된다.
- [ ] 성능/발열/배터리 기준을 충족한다.
